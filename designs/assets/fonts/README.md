# Local fonts

Unmodified Big Shoulders Display (300, 500, 600, 800) and Space Mono (400), downloaded from Google Fonts on 2026-10-23. `fonts.css` preserves the original family names and `font-display: swap`.

Source stylesheet: https://fonts.googleapis.com/css2?family=Big+Shoulders+Display:wght@300;500;600;800&family=Space+Mono&display=swap

Both families use the SIL Open Font License; see the accompanying OFL files. Font files are served locally so page rendering does not depend on Google Fonts connections.
